# 🚀 סוכן השיווק של אופק

סוכן AI שרץ בטרמינל ועושה בשבילך שיווק:

- ✂️ **עורך סרטונים שצילמת** בטלפון: מוסיף כיתובים בעברית, פס מיתוג וכרטיס סיום עם הטלפון שלך.
- 🎬 **יוצר סרטונים** קצרים (MP4) לטיקטוק, לרילס, לסטוריז וליוטיוב: טקסט מונפש, רקעים צבעוניים או התמונות שלך, ומוזיקה.
- ✍️ **כותב פוסטים** לאינסטגרם, לפייסבוק, לטיקטוק, ללינקדאין ולוואטסאפ.
- 🎯 **מוצא לקוחות פוטנציאליים** ברשת ושומר אותם בקובץ אקסל, יחד עם הודעת פנייה מוכנה.
- 🎥 **כותב פרומפטים לכלי וידאו AI** כמו Runway, Sora, Veo ו-Kling, בשביל סרטונים "אמיתיים" עם אנשים וסצנות.

---

## מה זה מפתח API?

**מפתח API** הוא כמו סיסמה אישית שמאפשרת לתוכנה (הסוכן) לדבר עם Claude דרך האינטרנט.

- מקבלים אותו באתר של Anthropic.
- **משלמים לפי שימוש**: כל פעולה של הסוכן עולה כמה סנטים. מומלץ להגדיר באתר תקרת הוצאה חודשית.
- **אסור לשתף אותו עם אף אחד**: מי שמחזיק במפתח יכול להשתמש בו על חשבונך.
- המנוי הרגיל של Claude (Pro או Max) הוא דבר נפרד ולא כולל מפתח API.

### איך משיגים מפתח (5 דקות)

1. נכנסים ל-[platform.claude.com](https://platform.claude.com) ונרשמים.
2. בתפריט **Billing**, מוסיפים אמצעי תשלום וטוענים קרדיט (אפשר להתחיל מ-5$). את זה עושים לבד באתר: הסוכן לא נוגע בפרטי אשראי.
3. בתפריט **API Keys**, לוחצים על **Create Key** ומעתיקים את המפתח (הוא מתחיל ב-`sk-ant-`).

## התקנה (פעם אחת)

**צריך:** Python 3.10 ומעלה ([python.org](https://www.python.org/downloads/)). ב-Windows, מסמנים בהתקנה את האפשרות "Add Python to PATH".

```bash
# 1. מורידים את הפרויקט
git clone https://github.com/ofek67/Ofek.git
cd Ofek/marketing_agent

# 2. מתקינים את מה שצריך (כולל ffmpeg לעריכת וידאו, אוטומטית)
pip install -r requirements.txt

# 3. יוצרים קובץ הגדרות
cp .env.example .env        # ב-Windows: copy .env.example .env
```

עכשיו פותחים את הקובץ `.env` בכל עורך טקסט ומדביקים את המפתח:

```
ANTHROPIC_API_KEY=sk-ant-המפתח-שלך
AGENT_PASSWORD=סיסמה-שרק-אתה-יודע
```

`AGENT_PASSWORD` היא אופציונלית. אם ממלאים אותה, הסוכן יבקש סיסמה בכל הפעלה, כך שרק אתה תוכל להשתמש בו.

## הפעלה

```bash
cd Ofek/marketing_agent
python agent.py
```

ומדברים איתו בעברית רגילה. בפעם הראשונה הוא ישאל אותך על העסק (מה אתה מוכר, למי ואיפה). אפשר גם למלא את הפרטים מראש בקובץ `business_profile.md`.

### דוגמאות

| מה כותבים | מה מקבלים |
|---|---|
| `תכין סרטון לטיקטוק על המבצע של השבוע` | קובץ MP4 בתיקייה `output/videos/` |
| `תכתוב 3 פוסטים לאינסטגרם לשבוע הקרוב` | קבצים בתיקייה `output/posts/` |
| `תמצא לי 10 לקוחות פוטנציאליים בחיפה` | הקובץ `output/leads.csv` (נפתח באקסל) |
| `תכתוב פרומפטים ל-Runway לפרסומת של 15 שניות` | קובץ בתיקייה `output/files/` |
| `תערוך את clip-1.mov ותוסיף את הטלפון שלי בסוף` | סרטון ערוך בתיקייה `output/videos/` |
| `תכין לוח תוכן לחודש` | קובץ בתיקייה `output/files/` |

### סרטונים עם התמונות או המוזיקה שלך

שמים את הקבצים בתיקייה `assets/` (למשל `product.jpg` או `music.mp3`), ואומרים לסוכן:
> תכין סרטון עם התמונות product.jpg ו-shop.jpg והמוזיקה music.mp3

מוזיקה: השתמש רק במוזיקה שמותר לך להשתמש בה, למשל מספרייה חינמית כמו YouTube Audio Library.

### פקודות

- `/new`: מתחילים שיחה חדשה.
- `/files`: רואים את כל הקבצים שנוצרו.
- `/exit`: יוצאים.

## איך יוצרים סרטון AI "אמיתי" (עם אנשים וסצנות)

הסוכן מייצר בעצמו סרטוני טקסט מונפש. בשביל סרטון מצולם ריאליסטי משתמשים בכלי וידאו AI, והסוכן כותב לך את הפרומפטים:

1. מבקשים מהסוכן: `תכתוב לי תסריט ופרומפטים ל-Runway לפרסומת`.
2. נכנסים לאחד הכלים: [Runway](https://runwayml.com), [Sora](https://sora.com), [Kling](https://klingai.com), [Pika](https://pika.art) או Google Veo (דרך Gemini). לרובם יש ניסיון חינם.
3. מדביקים כל פרומפט ומקבלים קטע וידאו של 5 עד 10 שניות.
4. מחברים את הקטעים באפליקציית עריכה חינמית כמו CapCut, ומוסיפים טקסט ומוזיקה.

## 🔒 בטיחות

- הסוכן **לא נוגע** בפרטי אשראי, בתשלומים או בסיסמאות.
- הסוכן **לא שולח הודעות** לאף אחד. הוא רק מכין טיוטות, ואתה מחליט למי לשלוח.
- הוא אוסף רק פרטי קשר עסקיים שפורסמו בפומבי, ושומר קישור למקור של כל אחד.
- הוא יכול לכתוב קבצים רק בתוך התיקייה `output/`.
- המפתח והסיסמה נשמרים רק במחשב שלך, בקובץ `.env`, שלא עולה ל-GitHub.

> 💡 לפני ששולחים הודעות שיווקיות: לפי חוק הספאם בישראל, אסור לשלוח פרסומות במייל, ב-SMS או בוואטסאפ בלי הסכמה מראש. מותר לשלוח לעסק פנייה אחת, שבה מבקשים את הסכמתו לקבל פרסומות. אם יש ספק, עדיף לפנות בטלפון או דרך טופס צור קשר באתר של העסק.
